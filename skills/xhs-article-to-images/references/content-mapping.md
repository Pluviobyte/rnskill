# 内容映射规则：文章 → 卡片页

排版前先读完本文件。

## 核心原则（默认模式：全文重排版）

**目标是把文章完整转成好看的 3:4 图文排版，不是做 8 页精华摘要。**

- **正文为主**：绝大多数页用 `body-pg` / `e-body-pg`；按文章小节顺序往下排
- **有图用图文**：段落自带配图 → `media-pg` / `e-media`；教程截图、界面图、步骤图优先保留
- **页型按需选用**：封面必做；金句 / 大字陈述 / 清单 / 三观对比等**只在内容天然适合时用**，不为凑花样硬塞
- **内容不阉割**：超容量就**拆页**，禁止删段落、删步骤、删列表项来凑页数
- **轻度润色即可**：断行、去口语赘词、标题可读化；保留事实、步骤、代码块、列表结构
- **页数不设上限**：一篇长教程排 15–18 页很正常；小红书单条上限 18 张，超出才和用户说要不要拆成两条

与「摘要 carousel」的区别：后者 6–10 页、钩子+骨架、细节放正文区；**本 skill 默认走全文重排版**。用户明确说「做摘要版 / 精华版 / 只要 8 页」时才切换。

五套设计皮肤 + 女性向三主题。**E 雅刊是默认皮肤**：用户没点名皮肤就用 E，不用纠结。其余在用户点名、或用户明确让你自由挑选时再按"气质"选：

| 皮肤 | 气质 | 适合 | 封面是否需要配图 |

| **A · 暖杏奶咖** | 米白底 + 焦糖暖金，爆款感 | 经验分享、干货合集、生活方式、暖调励志 | 否（纯排版） |
| **B · 雾松青** | 燕麦灰底 + 低饱和松绿，清爽治愈 | 文艺、治愈、轻松话题；**手里有一张好看的横图时优先考虑** | **是（16:9 横图）** |
| **C · 黛墨描金** | 象牙底 + 墨黑结构 + 细金线，编辑感 | 知识向、书单影单、理性克制的观点文 | 否（纯排版） |
| **D · 夜读鎏金** | 深墨底 + 鎏金大衬线，杂志惊艳感 | 深度思考、认知类长文、金句多、情绪浓的内容 | 否（纯排版） |

用户让你自由挑选时的判断顺序：

1. 拿不准就 **E**（默认，气质最百搭）

## 二、文章怎么拆页（全文重排版）

### 默认拆页逻辑

按文章 **H2 → H3 → 段落/列表/图片** 顺序扫描，映射到卡片：

| 文章元素 | 页型 | 说明 |
|----------|------|------|
| 标题 | 封面 cover | 封面标题可写钩子，副标/导语可概括全文；**不等于删掉正文** |
| 每个 H2 / H3 小节 | 正文 body-pg | **主力页型**；一个小节装不下就拆成连续多页，页眉 kicker 保持同一章节名 |
| 段落中的图片 | 图文 media-pg | **一张图一页**（或图+紧邻说明文字）；教程步骤截图不要合并丢图 |
| 长列表 / 步骤 / 插件清单 | 正文 body-pg 或 list-pg | 列表 ≤ 容量上限条数/页；超出拆页，**条目全保留** |
| 短代码块 / 配置示例 | 正文 body-pg | 用 `<pre>` 或等宽块放进正文页；太长拆页 |
| 文章结尾 | 正文 或 ending | 教程类可直接用最后一节正文收尾；需要 CTA 时加 ending |

### 页型选用原则

**常用（默认组合）**：封面 + 大量正文 + 有图则图文 +（可选）结尾

**少用、按需插入**（不是每篇都要）：

| 页型 | 何时用 | 何时不用 |
|------|--------|----------|
| quote 金句 | 文中有强金句、适合单独镇场 | 仅为「好看」编造金句 |
| e-statement 大字陈述 | 章节转场、核心反问 | 替代正文承载实质内容 |
| e-points 要点正文 | 小节本身是 3–4 条并列要点 | 把长段落硬压成 4 条摘要 |
| e-list 清单 | 插件名/书单/工具名列表，名字短 | 带长说明的步骤列表 |
| e-views 三观对比 | 文中有明确对比结构 | 强行制造对比 |

**禁止**：为「节奏变化」在正文之间硬插 quote / statement / views；**不要连续为了换页型而换页型**。

### 页数

- **默认**：以覆盖全文为准，通常 **10–18 页**；教程、配置 walkthrough 类偏多
- 用户说「摘要版 / 精华版 / N 页以内」→ 切换摘要模式（见文末）
- 小红书单条上限 **18 张**；超出与用户确认拆条或再压缩

## 三、每种页型的容量上限（防溢出）

超出上限 → **拆页**，**禁止缩小字号**，**禁止删内容凑页**。

### 皮肤 A/B/C

| 页型 | 容量上限 |
|------|---------|
| cover-a 封面 | 大标题 2–3 行、每行 ≤8 字（`<em>` 高亮 1–2 处）；副标 ≤40 字 |
| cover-b 封面 | 大标题 2 行、每行 ≤7 字；副标 ≤30 字；标签 3–4 个、每个 ≤6 字；hero 图 16:9 |
| cover-c 封面 | 大标题 3 行、每行 ≤6 字；副标 ≤40 字 |
| quote 金句 | 金句 ≤60 字（`<b>` 高亮一处）；署名一行 |
| body-pg 正文 | 标题 ≤2 行（每行 ≤10 字）；正文 2–3 段、总计 ≤160 字；可选 callout ≤40 字 |
| list-pg 清单 | 分类标题 1 个 + 条目 5–6 条；条目带 li-note 说明时最多 4–5 条，note ≤30 字 |
| media-pg 图文 | 标题 ≤2 行 + 一张 16:9 图 + 图注一行 + 正文 1–2 段 ≤90 字 |
| ending 结尾 | 大标题 ≤3 行、每行 ≤8 字；副标 ≤50 字；CTA 固定样式 |

### 皮肤 D

| 页型 | 容量上限 |
|------|---------|
| d-cover 封面 | 大标题 2 行、每行 ≤6 字；英文引言一句 ≤45 字符；副标 ≤40 字；水印字 1–2 字符 |
| d-quote 金句 | 金句 ≤50 字；水印取一个主题单字 |
| d-body-pg 正文 | 标题 ≤2 行；正文 2 段 ≤130 字 + 可选 callout ≤40 字 |
| d-list 清单 | 条目 5 条 |
| d-media 图文 | 同 media-pg，文字再少 20% |
| d-ending 结尾 | 大标题 ≤3 行、每行 ≤7 字 |

### 皮肤 E 雅刊（默认）

| 页型 | 容量上限 |
|------|---------|
| e-cover 封面 | 大标题 2 行、每行 ≤7 字（`<em>` 斜体高亮 1 处）；kicker 一行；导语 ≤60 字；底部横幅配图 |
| e-quote 金句 | 金句 ≤55 字（`<em>` 高亮一处）；署名「— 人名」 |
| e-statement 大字陈述 | 大字 2 行、每行 ≤8 字；副句 ≤30 字 |
| e-body-pg 正文 | 标题 ≤2 行；正文 2 段 ≤140 字 + 可选 `bp-pull` ≤30 字或 `e-note` |
| e-body-pg + e-points | 标题 ≤2 行 + 引入段 ≤50 字 + 要点 3–4 条（每条 ≤16 字）+ `e-conc` ≤20 字 |
| e-list 清单 | 条目 3–5 条，`li-name` 每条 ≤7 字；可选一条 `.on` 高亮 |
| e-views 三观对比 | 标题 ≤2 行 + 对照行 2–3 行 |

### 女性向三主题（femcard，F/G/H 共用同一套容量）

页型类名：封面 `fem-cover`、大字陈述 `fem-statement`、正文 `fem-body-pg`、编辑式清单 `fem-list`、要点正文（`fem-body-pg` + `fem-points` + `fem-conc`）、三观对比 `fem-views`、图文 `fem-media`、结尾 `fem-ending`。

| 页型 | 容量上限 |
|------|---------|
| fem-cover 封面 | 大标题 2 行、每行 ≤7 字（`<em>` 高亮 1 处）；kicker 一行；导语 ≤60 字；底部横幅配图 |

## 四、文案处理要求

### 全文重排版（默认）

- **按文章结构走**：H2/H3 映射为页标题或 kicker，顺序不乱跳
- **正文**：轻度润色（断句、去赘词），**不删信息点**；一段装不下就拆两页
- **列表 / 步骤 / 插件名**：尽量全保留；单页装不下拆页
- **代码 / 配置**：保留关键行；过长拆页或只保留必要片段并标注「接下一页」
- **封面标题**：可写钩子，但正文从第 2 页起忠实于原文
- 高亮每页最多 2 处，标结论词或术语

### 摘要 carousel（仅用户指定时）

- 6–10 页，钩子+骨架，细节放小红书正文区
- 正文压缩为「一句论点 + 一句证据」
- 可穿插 quote / statement / views 做节奏

## 五、配图规则

- **文章自带图全量考虑**：教程文里每张截图都应有归宿（media-pg 或封面横幅）
- 图槽 16:9 + `object-fit: cover`；UI/人脸被裁切时加 `object-position`
- 截图保持清晰可读
- 封面缺横幅图时：问一次（用户传 / 网图 / AI 生成）；用户说「看着办」→ 网图 → AI
- 网图来源记 `assets/SOURCES.md`

## 六、自检清单（全文模式）

交付前核对：

- [ ] 每个 H2 小节都有对应卡片（可能多页）
- [ ] 文章里的图片都已进入 media 页或封面
- [ ] 没有为凑页型删掉段落、步骤、列表项
- [ ] 无溢出、无贴边、无大面积无意义空白（空白是因为该页图大或转场，不是因为删光了字）
