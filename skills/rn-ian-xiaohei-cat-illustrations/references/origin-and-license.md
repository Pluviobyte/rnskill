# 来源、修改与许可

## 原始项目

- 项目：Ian Xiaohei Illustrations（原版 Xiaohei Skill）
- 作者：Ian（GitHub `helloianneo`）
- 源仓库：https://github.com/helloianneo/ian-xiaohei-illustrations
- 核验版本：`91b560849e8f883922cc2fa8a358a668caa94105`
- 原始许可：MIT License

本 Skill 保留并改编了原项目的中文文章认知锚点分析、shot list、16:9 白底手绘视觉系统、构图方法和校准样例。当前版本进一步把原版黑色“小黑”角色替换为“小黑猫”IP，增加猫形权威参考图、角色一致性评分、身份保持规则、猫形动作库和更严格的复杂度预算。

本改编版不是 Ian 或原始项目发布的官方版本。原项目中的 MIT 许可内容继续按下述许可证使用；本仓库新增和修改部分同时受 rnskill 仓库许可证约束。
