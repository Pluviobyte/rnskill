# ra-实操策划

## Goal

AI 当策划副驾，用户当出镜主角。产出一份「照着就能录」的策划稿：题组、结构、口播稿、操作清单全备，临场反应刻意留白（人味保留区）。

## 产线全景（策划稿 status 状态机）

```
策划(Claude) → 录制中(你) → 待粗剪(Codex·工具选择门) → 融合中(你·剪映) → 待字幕(Codex·ra-audio-to-subtitles) → 待动画(Codex·Remotion) → 成片 → 已发布
```

- 素材：口播 + 录屏两条流 → `01-内容生产/视频工作台/制作中/<日期-主题>/原始素材/`
- 粗剪交付：`<项目>/粗剪/口播-粗剪.mp4`（纯 MP4，喂剪映）
- 融合（用户手工）：全身段全屏；其余口播缩小放实操画面**左下角 PiP**
- 字幕：融合版作为唯一时间源，经 `ra-audio-to-subtitles` 生成真实词级
  时间戳、烧硬字幕并留 `.srt`（YouTube CC / B站字幕稿用）
- 动画：**只有全身出镜段**加 Remotion 组件 overlay，PiP 段不加
- 发布：B站 + YouTube 主发，抖音/小红书/视频号全量分发；成片 → `视频工作台/已制作/<月上旬|月下旬>/<日期-主题>/成片/` + 发布看板登记

## 策划稿结构方法论（实测对比片范式）

1. **钩子（10 秒内）**：热点事件 + 冲突问句 + 承诺（"X 刚发布，真比几天前的 Y 强吗？今天从 A/B/C 三方面对比"）
2. **前置暴论**：先抛一个反直觉体感结论当悬念（"同样任务，它快了 10 倍"），留住观众
3. **实测题组 ×N**：每题固定循环——念题（prompt 原文上屏）→ A 结果边看边评 → B 结果 → 单题裁决。题目要有**梯度设计**：从"符合要求吗"测到"纯拼某一维度"；维度要**覆盖面**（如前端/后端/文案各设题）
4. **中场小结 + 人味立场句**（"结果就是结果，我也不能说谎"类真实表态）
5. **总结**：分维度裁决，不和稀泥
6. **下期钩子**：留一个没测的维度（"agent 能力需要长期测，我会持续汇报"）
7. **结尾彩蛋**：互动悬念（"视频开头你猜是谁做的？"）

## 策划稿硬要求

- 按本 Skill 的 `assets/策划稿模板.md` 生成，一题一工程：`01-内容生产/视频工作台/制作中/YYYY-MM-DD-主题/策划稿.md`
- **口播稿分两层写**：全身段（开场/中场小结/总结——会加 Remotion 组件的段落）和 PiP 段（实测旁白要点）分开，全身段清单写进 frontmatter 供动画环节定位
- **每道测试题给可直接粘贴的完整 prompt** + 一句"这题看什么"（预期看点/可能翻车点）
- **临场反应不写死**：旁白只给要点，评价语和情绪反应留给你现场发挥——这是真人可信度的来源，禁止把每句话写满
- 录屏操作清单精确到步骤（开什么工具、输什么、录哪块屏）
- 片长按 frontmatter 契约控制；8-15 分钟默认 4-6 道题
- 对标参考只提取结构和题型，禁止照搬对标视频的原句和具体题目
- 策划完成后回链选题卡（无卡补卡），卡状态改已立项

## 与制作端的交接

- 你只改 status 和放素材，其余全自动：录完素材说一声或改 status=待粗剪；剪映融合完放回项目文件夹改 status=待字幕
- Codex 端职责见 `ra-video-production-director` 第 11-12 条；真人素材到位时
  默认用 ra-local-talking-head-cut：先交剪前校对 SRT 给用户确认，确认前禁止剪辑；
  确认后交付经过自然节奏、源参数、响度和 QC 验收的粗剪 MP4，并对最终 MP4
  重新生成生产字幕。多 take 用 video-use 提供选优证据；chengfeng 用作逐字审核或
  激进版对照；需要波形审核并把工程交给剪映/FCP 时用 AI剪口播导出 FCPXML。
  任一粗剪工具阻塞都不影响字幕走独立 Skill
