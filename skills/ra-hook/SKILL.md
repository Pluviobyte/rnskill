# ra-hook（钩子）：短视频开头钩子速查与决策

## Goal

Given a video topic or script, pick the right hook type by scenario, then draft the first 1-3 sentences using that type's template. This skill answers "用哪种钩子"; dbs-hook answers "这个钩子好不好"。两者配合：先用本 skill 定型，再用 dbs-hook 诊断打磨。

## 元原则（先于一切类型）

1. 钩子定带入，不定生死。开头最大的作用是让观众快速代入，真正能影响流量的是内容本身的质量。
2. 哗众取宠的钩子本质是欺骗观众。悬念可以留，承诺必须兑现。
3. 每种类型都有前提条件，前提不满足时该类型直接作废，换类型，不要硬套。

## 场景归类：按钩子的支点分三大类

| 大类 | 支点 | 类型 | 典型场景 |
|------|------|------|----------|
| 挂在内容上 | 内容本身够硬 | ① 内容预告 ② 价值包装 | 干货教程、稀缺体验、实操演示 |
| 挂在观众身上 | 观众自身状态 | ③ 现象前置 ④ 直击痛点 ⑤ 喊话观众 | 共鸣日常、垂类/带货、互动挑战 |
| 挂在事件上 | 一件具体的事 | ⑥ 事件开场 ⑦ 话题开场 | 故事叙事、观点讨论 |

## 决策流程

问一个问题：**这条视频最硬的东西是什么？** 按顺序排除：

1. 内容本身稀缺/反差（罕见体验、特殊身份、反常识组合）→ ① 内容预告
2. 能一句话说清观众看完能得到什么 → ② 价值包装
3. 观众有一个"我也这样"的共性窘境 → ③ 现象前置
4. 观众有一个明确、自知、想解决的痛 → ④ 直击痛点
5. 需要观众立刻动手/动脑参与 → ⑤ 喊话观众
6. 手里有一件带冲突的真事 → ⑥ 事件开场
7. 有一个能引战/引讨论的问题 → ⑦ 话题开场

都不满足？先回去补内容，不是补开头。

组合规则：一条钩子只选一个主类型，最多叠加一个辅助（常见：痛点 + 价值包装、事件 + 话题）。三个以上必然稀释。

## 七种钩子类型详解

### ① 内容预告

- 一句话概括本条视频最大看点。
- 前提：内容本身具备稀缺性。没有稀缺性时，把全片最精彩的片段/结论前置，达到同样效果。
- 模板：「（稀缺身份/反差组合）+（要做的事）」或「（最精彩结论前置），这条视频告诉你怎么做到的」
- 例：「47岁女生和小外甥去网吧的一天」「你的大学同学是一个54岁的阿姨，是一种怎样的体验」
- 常见错误：内容平平还硬做预告，观众看完正片觉得被骗 → 掉完播。

### ② 价值包装

- 开头就给足价值感，对抗瀑布流里没耐心的观众。
- 前提：收益必须能一句话说清，且正片兑现。
- 模板：「看完这条视频，你就能（具体收益）」/「为了（普遍目标），我们把（常见事物）爆改成了（意外形态）」
- 例：「看完这条视频，你就能无痛把盐戒掉」「为了让大家多喝水，我们把茶水间爆改成了游戏厅」
- 常见错误：价值承诺模糊（"看完收获很大"）= 没承诺。

### ③ 现象前置

- 把一个普遍现象放在开头，提升代入感，降低观众进入视频的成本。
- 前提：现象足够普遍，最好是"人间真实"级别。
- 模板：「不知道大家是不是跟我一样，（共性窘境细节）」
- 例：「每次出差或放假回家，行李箱就一直躺在房间里，根本不愿意收拾」「睡醒就刷短视频，一刷两小时」
- 常见错误：现象不够普遍，变成自说自话。

### ④ 直击痛点

- 痛点观众观看欲望最强，是最适合做开头的类型之一，尤其适合垂类账号（能直接激发消费需求）。
- 前提：痛点真实、具体、观众自知。
- 模板：「为什么你（努力了）却（得不到结果）」/「（痛点场景的具体尴尬瞬间）」
- 例：「为什么你朋友能力没你强，赚得比你多」「养猫会掉毛、减肥不掉秤，都是痛点」
- 常见错误：痛点是博主以为的，不是观众自认的。

### ⑤ 喊话观众

- 99% 的人刷短视频时不会主动思考，开头要主动发起互动，既拉探索欲也养粉丝粘性。
- 前提：指令具体、动作成本低、3 秒内能做。
- 模板：「如果你今年（身份/状态），（动作指令）」/「给你3秒钟想一下（具体问题），3、2、1」
- 例：「给你3秒钟想一下怎么在抖音上卖鸡」「接受粉丝的挑战」
- 常见错误：指令空泛（"评论区告诉我你的想法"），观众无感。

### ⑥ 事件开场

- 开头直接交代发生了一件事。
- 前提：事件必须带冲突。平铺直叙的事 = 流水账。
- 模板：「那天我（突发事件）」
- 例：「那天我出了车祸」「那天我偷拿了别人的东西，被抓个正着」
- 常见错误：事件无冲突，观众等不到张力就划走。

### ⑦ 话题开场

- 开头抛出一个能让更多网友参与表达的话题。绝大多数视频拍成流水账，本质是自说自话、没给观众参与空间。
- 前提：话题人人有立场、有话说。
- 模板：「（一个普通人/某类人）怎样才能（争议性目标）」/「你（某种隐秘心理）过吗」
- 例：「一个普通人怎样才能从零做到年入30万」「你嫉妒过自己的朋友吗」
- 常见错误：话题有标准答案，讨论空间为零。

## 与现有工作流的衔接

- 洗稿（ra-洗稿）时：先按决策流程为改写稿选定主开头类型，再进 dbs-hook 诊断前 5 秒。
- 选题深化时：可在选题卡上标注候选钩子类型，作为立项时形态判断的参考（强痛点题材更适合垂类短视频，强话题题材更适合观点口播）。
- 本账号主力赛道（AI 实操教程）：默认优先 ② 价值包装 和 ④ 直击痛点；纯观点口播优先 ⑦ 话题开场 和 ③ 现象前置。
